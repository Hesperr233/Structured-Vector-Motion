## 复现与数据边界

```bash
python -m pip install "Pillow==12.3.0"
python -m unittest discover -s tests -p test_fixture.py -v
PYTHONPATH=tests python -m video_restoration.fixture /tmp/svm-c-ci-r1-fixture --scenario combined
PYTHONPATH=tests python -m unittest video_restoration.media_smoke -v
```

PowerShell 下先设置 `$env:PYTHONPATH = 'tests'`，再运行对应的 Python 命令。生成器要求新目录且父目录已存在。每次运行使用独立临时目录，实践线和 CI 不共享可写样例。

序列为 256×256、灰度 PNG、12/1 fps、24 帧，时基 12 tick/s，帧 0–23 对应 tick 0–23，播放区间为 [0, 2) 秒。固定种子 6082026，使用带纹理的静态背景和每帧横移 6 像素的亮目标。提供 clean、damage、flicker、ghost、appearance、combined 六个场景，作用域为单张固定二值 Mask。可用 `--seed` 生成独立纹理。正式开发与留出样例需要在冻结时同时划分种子与运动/退化条件，单换纹理不足以检验泛化。几何和缺陷规则是测试专用草案。

生成目录中 `input/` 包含退化帧、Mask 和输入描述，`evaluation/` 包含 clean 帧、种子及场景。接入后只把 `input/` 和冻结配置复制到被测进程可读的环境，并与输出目录分离。评分进程单独持有真值。至少在无真值可读的环境运行一次，并更换评测参考复跑，核对输出语义摘要不变。文件 SHA-256 针对原始 PNG 字节，像素 SHA-256 针对行优先的 8 位灰度字节，解释摘要时同时校验模式和尺寸。此处 manifest 仅描述 fixture。

## 评分与门槛

- **合成真值**。像素 MAE 以 8 位灰度级计。ROI 和局部遮损分别取区域平均再取帧均值。背景闪烁取固定区域中相邻帧残差差值的绝对值均值，残差为输出减 clean。拖影对 tick 2–23 的预设轮廓外拖尾区计算与 clean 的 MAE。外观波动对运动目标内部的平均灰度残差计算相邻帧绝对差，另需约束内部空间偏差。边缘报告最坏帧的横向位置偏移和最坏边带 MAE。ROI 外计无损输出相对输入变动的像素总数。
- **无真值辅助指标**。可在人工指定的静态背景 ROI 统计帧间亮度波动、检测异常残影和边缘漂移，并检查 ROI 外相对输入的差异。运动区帧差受真实运动影响，用作排查信号。
- **人工审查**。同步播放 before/after/comparison，重点看首尾、遮挡或低证据帧、边缘锐度、残影、局部色漂以及修复边界。使用代表帧定位，观看完整视频核对时间一致性。

G1 的初始提议是每项非零的单项退化主指标比输入降低至少 30%，组合场景逐项改善，授权域外差异为零。输入指标为零时使用冻结的绝对保护阈值，不算百分比。同步冻结逐帧边缘与外观保真阈值、无退化样例保护、异常输入诊断以及 MP4 内容容差。现有回读 MAE < 5 仅用于独立编解码 smoke。自然视频、复杂遮挡、运动模糊、压缩链差异和跨平台媒体一致性仍缺证据。

## CI 与合并

现有 Ubuntu/Windows × Python 3.11/3.12 作业保留。新增实验 workflow 将快速 fixture/oracle 测试与 Linux 编解码作业分开。媒体作业安装 FFmpeg、打印 ffmpeg/ffprobe 版本并校验两者主次版本一致且至少 6.0。缺工具、工具错误或媒体回读失败使作业失败。Ubuntu 24.04 固定作业平台，APT 补丁版会变动，正式验收应记录精确版本或锁定工具镜像。实验媒体由测试生成，临时文件随测试结束清理。

产品合并前要求既有质量矩阵、独立 fixture 检查及接入实践线的产品端到端作业在同一候选 SHA 上通过，并以冻结契约验证单项和组合质量、逐帧保真、作用域外不变、确定性和输入保护。正式产品作业须验证全部交付 MP4 的解码内容、上传可复核的 manifest、指标、媒体和失败日志。主观质量由审查线看完整视频。当前 smoke 作业只证明测试数据、评分与工具链，产品作业仍待 G1/G2 接入。
